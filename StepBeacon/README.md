# StepBeacon

StepBeacon is an original iOS step tracker inspired by the strongest parts of apps like Pedometer++ while keeping its own identity and product shape.

## What it includes

- Today dashboard with step goal progress, distance, floors, pace, and streaks
- 7-day snapshot chart with weekly momentum callouts
- Trends screen for 7, 30, and 90 day history
- Achievement system for streak, distance, and stair milestones
- Settings for goal, distance units, floors visibility, and demo data
- Simulator-safe demo mode so the app can be built and tested without a physical iPhone

## Local testing

- Open `StepBeacon/StepBeacon.xcodeproj`
- Run the `StepBeacon` scheme on an iPhone simulator
- The simulator uses demo activity automatically
- UI tests launch with seeded demo data through `APPSTORE_SCREENSHOTS` and `STEPBEACON_DEMO`

## Product direction

This project intentionally aims for the glanceable, momentum-building side of step tracking:

- quick daily progress
- clear trends
- streak motivation
- milestone feedback

The implementation is original and does not copy third-party code or branding.
